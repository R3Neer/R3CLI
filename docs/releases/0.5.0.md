# R3CLI 0.5.0

R3CLI 0.5.0 expands the visual-language library into a first-class cross-shell presentation layer with an official Nushell adapter.

## Highlights

- Adds the native Nushell adapter for Nushell 0.115+, covering the same semantic colour roles, symbols, layout primitives, diagnostics, tables, and catalogue-driven help model used by the Python and PowerShell implementations.
- Adds deterministic Nushell packaging so products can vendor a reproducible adapter without requiring Python at runtime.
- Adds cross-language contract coverage for the packaged PowerShell and Nushell adapters.
- Fixes Nushell `auto` colour detection by making the decision at the final emission boundary, where terminal and redirection state are accurate.
- Preserves `NO_COLOR`, explicit `always` / `never` colour modes, ASCII fallbacks, and semantic status symbols across adapters.
- Keeps machine-readable product data outside R3CLI: the library owns human presentation, while consuming tools retain their own structured-output contracts.
- Rewrites the README around the actual architecture: semantic presentation primitives, one help catalogue, shell adapters, deterministic builders, vendoring, themes, and expected-error boundaries.

## Versioning

This is a minor release rather than a patch because the official Nushell adapter is a new public integration surface relative to 0.4.1.

## Validation

CI covers Python 3.11 and 3.14, wheel build and reinstall, the PowerShell adapter manifest and contract suite, Nushell 0.115.1 packaging and parsing, cross-language behavior, and pseudo-terminal regression coverage for automatic colour.
