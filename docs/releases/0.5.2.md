# R3CLI 0.5.2

This patch release clarifies when applications should use banners.

## Changes

- Normal command output should start with its result, subject, or status rather than a banner that repeats the invoked tool or command.
- The Python, PowerShell, and Nushell quick starts now demonstrate that lighter presentation.
- The banner primitive and the separate help-page presentation contract remain available.

## Compatibility

The runtime API, adapter formats, and machine-output behaviour are unchanged.
