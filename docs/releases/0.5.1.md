# R3CLI 0.5.1

This patch release prepares the existing Python API for installation from PyPI.

## Highlights

- Publishes the `r3-cli` distribution containing the importable `r3_cli` package, theme, symbols, and MIT license.
- Adds a release workflow using PyPI Trusted Publishing with separate build and publish jobs and no stored PyPI token.
- Clarifies package metadata and documents the local verification and release procedure.
- Keeps the public Python API and Rich dependency range unchanged.

## Validation

The release workflow runs the Python tests, builds wheel and source distributions, checks their metadata, and installs the wheel in a fresh environment for an import and render smoke test. The existing CI also checks the PowerShell and Nushell adapters.
